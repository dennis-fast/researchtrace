# ResearchTrace — interactive scientific evidence

ResearchTrace is a read-only, standalone visualization of **computable scientific arguments** and their provenance. This public repository distributes **selected static demonstrations**, not the authoritative scientific state or the underlying scientific-process-core implementation.

**[Open the real-case demonstration](https://dennis-fast.github.io/researchtrace/)** · [Explore labeled synthetic examples](https://dennis-fast.github.io/researchtrace/examples/synthetic.html)

The **first screen** explains the selected scientific result before showing
the graph. It displays the source-linked historical and reconstructed values,
recorded discrepancy and limitations, followed by selectable evidence details.
The full typed graph is available on demand below.

## Real case: bounded computational reproduction

The default demo displays a frozen, previously qualified research case derived from the [Grinsztajn et al. tabular benchmark](https://github.com/LeoGrin/tabular-benchmark), using a RandomForest/electricity result:

| Observation | Test accuracy |
| --- | ---: |
| Released historical default result | 0.8457756371663656 |
| Completed bounded CPU reconstruction | 0.8507425245835842 |
| Absolute difference (rerun − historical) | 0.004966887417218624 |

The reconstruction **completed** but did **not exactly reproduce** the historical result. The cause remains unresolved. This does **not** show that the published result was erroneous, that one result supersedes the other, or that the paper's broader findings failed reproduction. The case is represented as a **Finding and a Limitation, not an invented Claim**.

Use the **Scientific focus** selector and the graph's backward evidence, forward context and full-state modes to inspect what is represented. Additional details are in [RELEASE.md](RELEASE.md).

## Release provenance

The static HTML was generated by the existing ResearchTrace exporter from a frozen revision of the private `scientific-process-core` repository. The public files contain selected embedded scientific-state projections, including source identifiers and references to some **non-public** upstream records. Those private records are not made available by the public site; the public release alone does **not** permit independent end-to-end reconstruction of the underlying experiments.
